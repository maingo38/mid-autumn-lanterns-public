# 🏮 Mid-Autumn Lanterns

Kids colour a lantern on their phone → it flies onto the big screen and flutters.
Oldest lanterns fade out as new ones arrive. teamLab "Sketch Aquarium" style.

Runs entirely on **one laptop** at the booth. **No internet needed** — phones just
join the same WiFi.

## Run it

```bash
npm install          # once
npm start            # starts the server + prints a QR code
```

Then:
- **Big screen** (this laptop, plug into projector/TV): open `http://localhost:3000/screen` fullscreen (F11).
- **Kids' phones**: scan the QR in the terminal, or open `http://<laptop-ip>:3000`.
  The laptop's IP is printed on start (e.g. `http://10.0.0.5:3000`).

Test the whole flow on one machine: open the colouring page and the `/screen`
page in two browser tabs, colour + press **Xong ✓**, watch it appear on the screen.

## How it fits together

```
Phone (index.html)        Laptop (server.js)         Screen (screen.html)
──────────────────        ──────────────────         ────────────────────
colour on 2 canvases  →   POST /submit           →   socket 'new-lantern'
press Xong ✓              save PNG + SQLite row       add sprite, animate
                          emit to screen             flutter (sin sway)
                                                     oldest fades when >80
```

## Add real lantern templates

Each template = **two PNGs**, same size, in `public/templates/`:

| File | What it is |
|------|-----------|
| `<name>_lines.png` | Black outline, **transparent inside** — kids colour into this |
| `<name>_mask.png`  | **Solid silhouette** (opaque = inside) — clips paint to the shape |

The sample `star` was generated by `python3 make_sample_template.py`. Give the
designer that script's output as the spec: outline layer + silhouette layer.

Open a specific template on the phone with `?t=<name>`, e.g.
`http://<laptop-ip>:3000/?t=carp`. Put a QR per template at each colouring station.

## Tunable knobs

- `server.js` → `MAX_ON_SCREEN` (default 80): how many lanterns stay alive.
- `screen.html` → `targetScale`, `amp`, `drift`: size and how much they sway.
- Glow: `screen.html` → `ctx.shadowColor / shadowBlur`.

## At the event — checklist

1. Laptop on, `npm start`, screen page fullscreen on the projector.
2. Phones on the SAME WiFi as the laptop (a cheap dedicated router is safest).
3. Print the QR; put it at each station.
4. All submitted art is saved in `public/lanterns/` + `lanterns.db` — back this
   up at the end; you can reprint or replay it.

### ponytail: single-laptop, canvas-2D, SQLite-file — deliberately no cloud/DB/3D.
Upgrade paths if ever needed: swap canvas→PixiJS for 1000+ lanterns; add a second
WiFi router for >50 concurrent phones; add an image-compress step if network lags.
